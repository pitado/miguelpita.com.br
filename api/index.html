Receitando API

API de produção do Receitando: receitas, ingredientes, matching por compatibilidade e autenticação.

https://api.receitando.miguelpita.com.br
GET /api/health

Healthcheck do Worker da API.

GET /api/ingredients

Lista o catálogo de ingredientes disponíveis no sistema.

GET /api/recipes

Lista as receitas cadastradas.

GET /api/recipes/slug/:slug

Busca os detalhes de uma receita pelo slug.

POST /api/recipes/match

Compara ingredientes disponíveis e calcula compatibilidade com receitas.

POST /api/auth/register

Cria uma conta e inicia a sessão.

POST /api/auth/login

Autentica um usuário.

GET /api/auth/me

Retorna o usuário da sessão atual.

POST /api/auth/logout

Encerra a sessão autenticada.

Matching

O núcleo da ideia: informar o que você tem em casa e receber as receitas ordenadas pela compatibilidade. 

curl -X POST https://api.receitando.miguelpita.com.br/api/recipes/match \
  -H "Content-Type: application/json" \
  -d '{"ingredients":["ovo","banana","farinha de trigo","leite"]}'
